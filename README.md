# ResolveIT

ResolveIT é um projeto pessoal que desenvolvo para aprender e praticar desenvolvimento de aplicações, com o auxílio do Codex na implementação e na compreensão do código.

A aplicação permite cadastrar usuários, abrir chamados de suporte e acompanhar seu atendimento. Usuários acessam apenas seus próprios chamados, enquanto administradores gerenciam as pessoas e os atendimentos.

O backend utiliza Java, Spring Boot, Spring Security e PostgreSQL. A interface é construída com React e TypeScript.

O projeto está em desenvolvimento e evolui conforme avanço nos estudos.
